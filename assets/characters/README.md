# Character image folders

Put reviewed/approved images in folders named with the character slug.

Examples:

- `assets/characters/yinlin/01.jpg`
- `assets/characters/yinlin/02.jpg`
- `assets/characters/changli/01.jpg`
- `assets/characters/the-shorekeeper/01.jpg`

The site looks for `01.jpg` through `12.jpg` when `VIEW ALL` is clicked.

Keep restricted/minor-coded characters SFW-only and do not add adult images for them.
